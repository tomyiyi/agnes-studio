01

基础设计原则

不可妥协的四条铁律，覆盖安全区、转化、画质与品牌一致性。

A

安全展示区铁律

核心文案、主体人物、关键图标必须置于绝对安全区。列表遮罩、状态栏、标题条、点赞区均按实机坐标预留，杜绝截断。

  • 微信标题遮挡带：底部 25% 高
  • 小红书信息遮挡带：底部 28% 高
  • 左右最小安全边距：≥ 6% 画宽
B

3 秒视觉转化

焦点层级固定为：第一视觉冲击（场景/主物料）→ 第二主标（痛点/利益点）→ 第三副标（证据/时间/人物）。

  • 主标占画面宽度 55–75%
  • 主标与背景对比度 ≥ 4.5:1
  • 单屏信息块 ≤ 3 组
C

画质高保真交付

禁止低分辨率拉伸。统一 2× / 3× 超采样出图，导出前轻锐化（USM 0.3–0.5px），抵抗微信/小红书有损压缩。

  • 色彩空间：sRGB IEC61966-2.1
  • 格式：PNG-24（保留锐度）
  • 字缘：亚像素抗锯齿开启
D

全局视觉一致性

微信封面、小红书卡片、项目 Landing 共用同一色卡、同一字阶、同一圆角与描边语言，形成可识别品牌资产。

  • 品牌主强调色：#E11D48
  • 正文墨色：#111827
  • 字体家族 ≤ 3 套/画面

03

微信公众号封面工程

头条 2.35:1 + 次条 1:1。重点规避常读列表标题遮挡与分享卡片裁切。

比例框按真实裁切逻辑绘制，可直接对照构图

版面骨架（可复用模板）

  1. 上带 8–18%：品牌眉标 / 栏目 / 日期，字高 28–36px（@2x）
  2. 中带 18–62%：主视觉或人像，人物面部避开垂直中线 ±12% 的文字叠压区
  3. 标题锚点：左对齐或居中，主标字高 72–96px（@2x），字重 Bold/Black
  4. 底带 75–100%：只放期号、色块、条码式装饰——允许被标题条覆盖

微信场景裁切备忘

场景风险对策
常读 / 订阅列表底部标题条遮挡约 20–25%主标上移，禁放底边
聊天分享卡片左右轻微裁切关键字左右留 6%
搜一搜 / 历史缩略放大糊化笔画最细 ≥ 6px @2x
04

小红书卡片爆款工程

主推 3:4 竖版 1080×1440。信息流缩略强对比，底部信息区严格避让。

底部 28% 对应标题 + 作者 + 互动栏叠压

卡片信息层级（3 秒法则）

L1
场景 / 物料占版 40%+，一眼可辨的主视觉
L2
主标题6–14 字，痛点或数字利益点，字高 96px+
L3
副标 / 证据20 字内，字号约主标 35–40%

网格与构图

  • 安全区内再分 3×3 九宫，主标占中上行两格
  • 色块分割线用 4–6px 硬边（@2x），忌柔和渐变堆叠
  • 单套字体家族 ≤ 3：显示体 / 正文体 / 等宽数字
05

项目落地页 / 品牌包装

Landing、文档头图、README 横幅与封面卡片共用同一设计语言。

Hero 首屏

  • 视口基准 1440×810 逻辑稿，导出 2560×1440
  • 标题字阶：H1 56–72px / H2 28–36px / Body 16–18px
  • 左右留白 8%，底 12% 避免与 CTA 抢焦点
  • CTA 按钮高 44–48px，主色填充 #E11D48

OG 社交分享卡

  • 固定 1200×630（1.91:1）
  • Logo 左上，标题左中，避免两端 10% 边缘
  • 与头条封面同一摄影/材质语言，只换排版

README / GitHub 横幅

  • 建议 1280×640 或 1920×640
  • 暗底用 #0A0B10，文字 #F9FAFB，对比 ≥ 4.5:1
  • 与 Agnes Studio 瑞士网格 / 赛博 HUD 流派共用色标
