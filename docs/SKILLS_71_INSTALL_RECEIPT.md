### 光色与氛围改造 · 6 项

- **S11** 电影印相 → `kodak-2383-film-look`
  - 在带擦拭肌理的底板上排列原始照片与电影感印相，加入局部光晕、乳剂溢边、套色偏移和漏光。
- **N01** 工业夜景 → `neil-monochrome-night-v0-1`
  - 工业雾霾、冷暖补色和局部霓虹的环境夜景重构。
- **N24** 电视重摄感 → `phosphor-relay-style`
  - 像重新拍摄电视直播画面：荧光点阵、屏幕光与信号衰减；不同于 CRT 界面设计。
- **N25** 星夜悬浮 → `starlit-relic-v1`
  - 深蓝夜空中的悬浮单物体，星芒、光晕、色散和胶片颗粒。
- **S04** 现实重新布景 → `reality-restaged`
  - 保留人物动作与关系，用尺度反差、大片色墙和不可能空间重新布景，保留摄影质感。
- **ST13** 星年夜色弥散 → `starryear-diffuse-gradient` · **Starryear 个人学习/非商业**
  - 上方保留未改动的16:9真实照片，下方把同一主题重构成柔和通透的夜色弥散渐变。

### 照片转插画与材质 · 14 项

- **S23** 极简插画 → `gc-universal-field-study`
  - 暖米白底、少量淡色、细线与大留白，把照片压缩为少数可辨认的形态。
- **S24** 旅行速写 → `photo-to-travel-sketch`
  - 用游走的黑色轮廓、干性马克笔和带灰度的少量色彩，把旅行照片画成一张省略细节的随手速写。
- **S25** 选择性钢笔速写 → `selective-ink-sketch`
  - 纯黑钢笔线条，一个重点细画，其余省略；用排线表现灰度，保留断笔和修正痕迹。
- **S26** 东方水墨双联 → `eastern-ink-photo-diptych`
  - 上方保留照片，下方转换为淡彩水墨，使用少数色块、柔和墨迹和充足留白。
- **S28** 阳光色块插画 → `sunwoven-reverie` · **上游非商业，商用需授权**
  - 用大色块、几何重组和鲜明光线重新组织照片，画面明亮，轮廓具有平面设计感。
- **N08** 街拍人物插画 → `street-photo-illustration`
  - 保留实拍街景，只把人物替换成黑墨或彩色卡通角色。
- **N09** 微型记忆插画 → `photo-revival`
  - 白纸上极小的手绘记忆片段，局部鲜艳色彩和细小手写字。
- **N20** 无字水墨解构 → `dyy_photo_deconstruct`
  - 旧纸上的无字水墨轮廓解构，用剪影或极少线条保留原场景。
- **N16** 粗颗粒像素 → `8bit-pixel-art`
  - 粗颗粒、柔边的抽象像素主体；不同于已收录的细点阵编辑海报。
- **S12** 复古电脑界面 → `tait-crt-interface-skill`
  - 把主体重画成粗像素、棋盘抖色与复古窗口的组合，再加入扫描线、辉光和球面屏幕畸变。
- **N03** 拼豆海报 → `yq-fuse-bead-poster`
  - 上方原照，下方热熔拼豆场景；保留颗粒实体质感，不等同像素滤镜。
- **N15** 蒸汽朋克 → `steampunk-image-skill`
  - 黄铜、齿轮、维多利亚工程图和机械构造，支持照片改造、海报与头像。
- **S13** 材料艺术 → `zone-material-art`
  - 用木、砂、石膏、金属或透明材料的拼接与穿插，把照片或主题转译成有厚度、支撑和空间关系的艺术装置。
- **ST10** 星年静观三联 → `starryear-quiet-witness-triptych` · **Starryear 个人学习/非商业**
  - 将单张照片从真实证据递进为北宋画意的超现实空间，再收束成带框的极简余像。

### 照片转编辑海报 · 23 项

- **S01** 千禧撞色海报 → `y2k-pop-poster`
  - 把主体从照片里切出来，用高饱和撞色描边、星芒、波点和短标题，做成千禧年杂志式海报。
- **S02** 超现实波普拼贴 → `surreal-pop-collage`
  - 保留黑白摄影作为现实锚点，用平涂色块换掉环境，再放进一个尺度不可能的巨物，制造明亮、荒诞的视觉反差。
- **S03** 日常照片游乐场 → `daily-photo-playground`
  - 在大面积暖白留白中，用高饱和色场、放大的主体、少量几何形和一扇小原照窗口，重排日常照片的情绪。
- **S05** 少色编辑海报 → `mono-color`
  - 用一到两种油墨、网点和大块留白建立编辑版式，图像与文字像真正印在纸上，而非给照片套单色滤镜。
- **S07** 昆汀电影海报 → `neil-quentin`
  - 用整片高饱和底色、硬边高反差主体、金黄粗标题和旧纸磨损，重构成三至四色的复古电影海报。
- **S08** 细点阵海报 → `pixel-style-poster-skill`
  - 用细密点阵、低分辨率印刷纹理和克制色彩表现大主体，再让标题与小注释贴近图像，形成诗意版式。
- **S09** 孔版印刷海报 → `photo-riso-poster`
  - 两三色套印、颗粒、轻微错版和纸感，把照片或文字变成安静的档案式海报。
- **S10** 场景艺术实验室 → `scene-to-art-lab`

- **S15** 潘通色卡海报 → `create-pantone-photo-posters`

- **S17** 群像剪影拼贴 → `silhouette-group-collage`

- **S29** 商品 × 涂鸦 → `heytea-doodle-poster`
