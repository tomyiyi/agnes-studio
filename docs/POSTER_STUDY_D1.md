# 海报学习 D1 · 带练拆解（示范笔记）

> 样本：`outputs/skill71_hifi_p0/S09_孔版印刷.png`（Agnes 出图，风格锚 photo-riso-poster）
> 目的：学会「拆结构」而不是抄画面。看完请自己再拆一张商业封面。

## 1. 第一眼 · 它在卖什么感觉

安静、档案、手作孔版；像一页野外笔记而不是广告海报。  
**高级感来源**：大量空纸 + 唯一视觉簇 + 印刷瑕疵（网点/微错版），而不是特效堆叠。

## 2. 五步拆解

| 维度 | 本张表现 | 可参数化 |
| --- | --- | --- |
| 主体事实 | 坐姿人物剪影、折叠椅、盆栽 3–5、花盆 | 1 人 + 道具簇；匿名剪影 |
| 构图 | 簇偏右下，不居中；无地平线 | 主体占宽约 15–20% |
| 负空间 | 上半几乎全空纸 | empty_paper ≈ 65–75% |
| 字阶 | 「terrace / afternoon」两行小字；无巨型主标 | 字服从图形；tracking 略开 |
| 色 | 靛蓝主墨 / 叶绿 / 朱橙 | 2–3 墨，角色可追溯 |
| 材质 | 纸纤维、网点、边缘墨渗、轻微错版 | print process = riso |
| 文案 | 英文极短、可拼对 | 禁长段、禁乱码 |

## 3. 若我要重做，改哪里

1. slogan 再短（一行 3–4 词）  
2. 档案字（NO./天气）字距 +8%  
3. 空纸再多 5%，簇再往右下推一点  
4. 只保留一种辅助墨（去掉第三色）

## 4. 你今天的练习（30 分钟）

1. 打开 `outputs/covers/` 里任一商业封面  
2. 填表：T1/T2/T3/T4 各写了什么？留白在哪？色角色？  
3. 用一句话写「不够高级的 1 处」  
4. 回写一条到 `data/learned_poster_rules.json`
