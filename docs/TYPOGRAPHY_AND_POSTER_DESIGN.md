# 商业海报设计、排版网格与中文字体工程指南 (Typography & Poster Engine)

> 本指南结合 GitHub 顶级高星开源排版规范（`sparanoid/chinese-copywriting-guidelines`、`vercel/satori`、`atelier-anchor/smiley-sans`、`lxgw/LxgwWenKai` 等），为 Agnes Studio 建立一套工业级的海报版式构建体系与中文字体选择标准。

## 一、海报排版四大构图法则与网格系统 (Grid & Composition)

海报设计不是文字与图像的随意堆砌，而是严格受控的**视线引导与能量流动**。

```
+-------------------------------------------------------------+
|  [Tier 1] 主标题：视觉第一着力点 (占比 15%~25%)              |
|  [Tier 2] 英文副标题：细线衬线/字间距撑开 (Tracking +300)    |
|  [Tier 3] 故事 Slogan：叙事微文案 (左对齐/居中微排版)         |
+-------------------------------------------------------------+
|                                                             |
|                                                             |
|           [Hero Visual] 纯净 AI 生成底图主体                |
|           (严格保留负空间，不被文字肢解遮挡)                 |
|                                                             |
|                                                             |
+-------------------------------------------------------------+
|  [Tier 4] 商业装饰层：演职员列表 / 条形码 / 经纬度坐标 / 印章 |
+-------------------------------------------------------------+
```

### 1. 负空间留白率法则 (Negative Space Ratio)
- **黄金区间：画面 25% ~ 35% 必须维持干净的负空间**。
- **生图阶段即刻控制**：在提示词中必须显式定义负空间方位（如 `clean negative space reserved in the upper-left quadrant for commercial typography`），禁止让复杂杂物（建筑尖顶、繁琐机械零件）侵入文字排版区。

### 2. 视觉层级四级跳 (Visual Hierarchy Tiers)
- **Tier 1 - 核心大字标 (Hero Title)**：
  - 字号极大，字重最高。占据整个海报的视觉定海神针。
  - 必须进行字间距微调（汉字紧密舒缓平衡，建议 0.1em~0.15em 呼吸间距）。
- **Tier 2 - 西文辅助字标 (Latin Subtitle)**：
  - 中英双语混排的关键配角。通常采用全大写（ALL CAPS），字号仅为中文的 25%~35%，但**字符间距（Letter Spacing / Tracking）大幅拉伸 200%~400%**，形成轻重对冲。
- **Tier 3 - 叙事文案 (Slogan & Tagline)**：
  - 承载故事核心（如“她修理时间，也修理人心”）。字号适中，字距自然，带有情感呼吸感。
- **Tier 4 - 工业与设计感修饰元数据 (Micro Decors)**：
  - 电影海报标配的演职员微文字（Billing Block）、条形码（Barcode）、经纬度坐标、作品编号（No. 001/025）、朱砂红印章。

## 三、中文海报排版五大铁律 (Typography Golden Rules)

借鉴 `sparanoid/chinese-copywriting-guidelines`（40k+ Stars）的经典规约：

### 1. 盘古之白（中英文混排呼吸间隙）
- 汉字与西文字母、数字相遇时，**必须保留 0.25em 左右的物理微间距**。
- **正例**：`铜钟与蒸汽城 STEAM & CHIME`
- **反例**：`铜钟与蒸汽城STEAM&CHIME`（紧贴粘连导致阅读压迫与业余感）。

### 2. 直角引号与标点规范
- 海报与现代平面设计中，优先使用直角引号「」与『』，杜绝劣质弯引号（“”）造成的排版重心不稳。
- 标点符号禁止堆叠，严格执行“避头尾”法则（逗号、句号、顿号不得孤立出现在行首）。

### 3. 中西文字体风格同构
- **宋体（Serif）必须搭配西文衬线体**（如 Garamond、Bodoni、Playfair Display 或 Times New Roman）。
- **黑体/得意黑（Sans-Serif）必须搭配西文无衬线体**（如 Inter、Helvetica Neue、Futura 或 SF Pro）。
- 严禁将古典宋体与夸张的圆体或卡通西文字体生硬拼凑。

### 4. 光影投影与材质呼应 (Shadows & Halos)
- 避免直接使用粗暴的高斯模糊黑阴影（容易显得脏和廉价）。
- 商业级排版采用**环境光同色系渐变阴影**（Ambient Tone Shadow）：
  - 暖调黄铜场景：阴影采用深琥珀色 `rgba(45, 25, 10, 0.65)`；
  - 冷夜深蓝场景：阴影采用藏青夜空色 `rgba(10, 15, 30, 0.75)`；
  - 辅以 1~2 像素金箔渐变高光轮廓。
