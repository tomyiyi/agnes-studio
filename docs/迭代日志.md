## 第 27 轮（2026-10-04）—— 多网关地址统一安全校验与连通性测试模型分类回显

**主题**：统合多网关合法性判定函数 `is_configured_gateway`，完善 `/api/test-connection` 多网关支持、密钥注入 SSRF 防护及 `chat_models` 分类回显。

**缺口发现**：
- 早期服务端仅具备单一 `base_url` 或图像专属 `is_configured_image_gateway` 判定，无法统一校验包含 `chat_base_url` / `image_base_url` 的多网关配置集；
- `/api/test-connection` 端点此前仅接受 `base_url`，当前端或脚本传入 `chat_base_url` 或 `image_base_url` 时报 400 缺少有效地址；
- `/api/test-connection` 仅过滤并返回 `image_models`，未分类返回对话模型（`chat_models`），前端缺少对话连通性的精细反馈；
- `/api/test-connection` 在注入服务端本地密钥时原仅对比 `local_cfg["base_url"]`，未支持 `chat_base_url` 或 `image_base_url`，同时缺乏非字典/空值等异常边界防御。

**改动点**：
1. `scripts/studio_server.py`：
   - 新增 `is_configured_gateway(target_base, local_cfg)`：统合配置的 `base_url`、`chat_base_url`、`image_base_url`，支持未配置时对默认端点的回退判定，严密规范化首尾空白与斜杠；
   - `/api/test-connection`：输入地址支持 `base_url` / `chat_base_url` / `image_base_url` 依次回退；
   - `/api/test-connection`：通过 `is_configured_gateway` 严密收紧服务端密钥注入，阻断 SSRF 风险；
   - `/api/test-connection`：探活模型响应增加 `chat_models` 提取与默认回退；对响应内容解码增加 `errors="replace"` 与字典类型校验；
   - 背景图目录白名单判断使用 `Path.is_relative_to` 提高健壮性。
2. `tests/test_studio_gateway_health.py`：
   - 新增 `TestIsConfiguredGateway` 测试类，覆盖多网关全键匹配、尾斜杠归一化、未探测时默认回退、空值及非字典非法参数安全防御；
   - 新增 `TestTestConnectionRoute` 测试类，覆盖 `chat_base_url` / `image_base_url` 地址回退、`chat_models` 返回以及合法配置网关注入密钥与外部未配置网关密钥隔离。
