## 第 4 轮（2026-10-01）：hssh 链中 heredoc 失效

- **现象**：经 `~/workspace/bin/hssh omarchy '... python3 - << "PYEOF" ... PYEOF'` 下发多行 python 补丁脚本，远端报 `/bin/bash: -c: line 6: syntax error near unexpected token '('`——bash 把 python 代码当 shell 解析，heredoc 未生效。
- **根因**：heredoc 操作符写在 hssh 单引号包裹的远程命令串里，经 hssh→ssh→远端 `bash -c` 多层转义后，`<< "PYEOF"` 重定向语义丢失（此前 `cat >> file << "EOF"` 能用是因为 heredoc 紧跟本地命令、本轮是嵌在引号内传参，两种形态不等价）。
- **定位**：对比成功/失败两条命令的形态差异确认；远端报错行号（line 6 = python 元组行）证明 python 源码进了 shell 解析器。
- **解法**：本地 `write` 工具写补丁脚本文件 → `scp -P 2223` 经主隧道（garbage.vicp.net:2223）送到 omarchy `/tmp` → `hssh` 单行执行。已验证 OK，后续跨机多行脚本统一走此通道，不再用引号内嵌 heredoc。
- **搜索**：GitHub/全网——hssh 为本工作区自研隧道包装脚本，无相关公开 issue/PR；**未找到现成方案，自研解决**。
